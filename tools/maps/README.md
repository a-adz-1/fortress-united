# Map tools

- `make_wad.py`: builds `fortress_united.wad`, the `fu_` textures for mappers
  (also copied to the TrenchBroom game folder and `Assets/StreamingAssets`).
- `bsp_entities.py`: edits a compiled `.bsp` without recompiling (map
  settings, entities, texture names), to try Fortress United settings or
  retrofit an existing map.

See [docs/mapping-guide.md](../../docs/mapping-guide.md).
